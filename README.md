# ふるさと納税マネージャー

ふるさと納税の「控除上限の目安」と「あといくら寄付できるか（残り枠）」を管理するPWAです。

## 機能

- 年収＋家族構成から控除上限の目安を計算（総務省早見表準拠・線形補間）。ポータルの詳細シミュ結果での手動上書きも可
- 寄付の記録（日付・自治体・金額・返礼品メモ）と残り枠バー表示
- ワンストップ特例チェック（5自治体以内判定・申請書の未提出件数・提出期限）
- 年ごとの管理（翌年は自動で新しい枠）
- JSONエクスポート／インポート（機種変更・バックアップ用）

## データについて

すべてのデータは端末のブラウザ内（localStorage）にのみ保存され、外部サーバーには一切送信されません。

## 免責

本アプリの上限額はあくまで目安であり、税額を保証するものではありません。個別の税務相談には応じられません。
正確な情報は[総務省 ふるさと納税ポータルサイト](https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/)、または税理士・お住まいの自治体にご確認ください。

## 技術構成

ビルド不要のPWA（HTML + CSS + JS + manifest + Service Worker）。Service Workerはネットワーク優先・オフライン時キャッシュ。
